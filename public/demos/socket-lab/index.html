Under the hood

A visual model of bounded TCP concurrency.

The original Python server uses a thread per connection, a lock-protected cache, a fixed backlog, and command-based file retrieval. Every endpoint in this browser demo is simulated.

  1. 01AcceptTCP handshake establishes a session.
  2. 02DispatchA worker thread handles each connection.
  3. 03RespondCommands return status, files, or ACKs.
